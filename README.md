# Grounded-Dreamer

Project website for **Grounded-Dreamer: Robot Learning from World Model Synthetic Data with Physical Grounding**.

**Website:** https://fffstrong.github.io/Grounded-Dreamer/

This repository contains the project website. Research code is coming soon.

## Website

Static HTML, CSS, and JavaScript. No build step is required. GitHub Pages serves the `main` branch from the repository root.

- `index.html`: project content, authors, results, and citation
- `style.css`: responsive layout
- `script.js`: policy result selector, image enlargement, and citation copy
- `Grounded-Dreamer.pdf`: public preprint
- Images: figures from the manuscript

Feng Jiang, Shu Chen, Yuanfei Wang, Yuan Li, Zhenhao Shen, Jiaqi Liang, Yang Chen, Lei Wei, Chen Xie, Ruihai Wu.
